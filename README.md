# OficinaDiag

Windows USB phone-diagnostics tool — retro 90s/2000s terminal look,
free local scans and Pro reports via [oficinaos-cloud](https://github.com/braindeadpt/oficinaos-cloud) for shops on
[OficinaOS](https://github.com/braindeadpt/OficinaOS).

> **Ecosystem:** this is 1 of 4 repos (the shop app `OficinaOS`, `oficinaos-cloud`,
> `oficinaos-website`, this tool). The canonical map — data flows, module
> IDs, where each piece lives — is in
> [`docs/ecosystem.md`](https://github.com/braindeadpt/OficinaOS/blob/main/docs/ecosystem.md)
> of the app repo.

## Download (testers)

**[oficinaos-diag-win-x64.zip — latest release](https://github.com/braindeadpt/oficinaos-diag/releases/latest/download/oficinaos-diag-win-x64.zip)**

1. Unzip the whole archive (don't pull the exe out of the folder — it needs the files beside it)
2. Run `OficinaDiag.exe` — if Windows warns you, see [SmartScreen](#windows-warning-smartscreen)
3. **Android**: enable "USB debugging" in the phone's developer options and connect by cable
4. **iPhone**: needs the Apple USB driver (iTunes or the "Apple Devices" app installed); accept "Trust this computer" on the phone.

## What it does

### Free — always, no account, no server

- **USB scan**: model, serial, OS version, battery (level, temperature, cycles,
  real vs design capacity where the manufacturer exposes it), storage, RAM, sensors,
  root/bootloader flags (Android) or activation/carrier (iPhone)
- **Screen + touch test on the phone**: the app serves a test page on the local
  network — Android opens it by itself via `adb`, iPhone reads a QR code. Results
  come back to the PC: dead pixels and dead touch zones are recorded
- **Export**: retro HTML report (printable → PDF) + raw JSON
- **Local history**: previous scans in `%APPDATA%\OficinaDiag` — compare battery
  health over time

### Pro — via oficinaos-cloud

- **AI report** (`ai-reports`): the raw scan data becomes a plain-language
  report for the customer — generated on the server, nothing runs locally
- **Send to shop** (`intake`): the customer at home enters the shop code and the
  diagnostic arrives at the shop's OficinaOS app as a pre-check — repairs,
  used-device buy/sell, grading

**Pairing the diag with a shop (Pro):** in Options paste a **pairing code**
(XXXX-YYYY, generated by the shop's OficinaOS app or by support) — the diag
exchanges it for a `diag`-scoped token, which only serves AI reports and never
touches the rest of the shop. A direct token is also accepted (legacy).

## Device support

| Platform | How | Phone requirements | PC drivers |
|---|---|---|---|
| Android | bundled `adb.exe` | USB debugging enabled | none |
| iPhone/iPad | libimobiledevice (imobiledevice-net) | "Trust this computer" | Apple USB driver (iTunes/Apple Devices) |

## Build

Requirements: [.NET 10 SDK](https://dotnet.microsoft.com/download) and PowerShell.

```powershell
tools\fetch-tools.ps1          # downloads platform-tools (adb) once
dotnet publish src/OficinaDiag -r win-x64 --self-contained `
  -p:PublishSingleFile=true -o publish
```

The result is `publish\OficinaDiag.exe` + `tools\platform-tools\` beside it —
portable, just copy the folder.

Pure-logic tests (submit validation, idempotency, AI-report HTML, update
origin) — run on Windows, Linux or macOS:

```powershell
dotnet test tests/OficinaDiag.Tests
```

## Windows warning (SmartScreen)

On first run Windows shows "Windows protected your PC" — that's normal:
the exe has no code signature, so SmartScreen has no reputation for it.
Click **"More info" → "Run anyway"** (it only asks once per file). It's not
malware — just a home-grown program without a certificate.

Two ways to end the warning: Microsoft Store (free, Microsoft signature —
pipeline ready in [`docs/microsoft-store.md`](docs/microsoft-store.md))
or code-signing the exe (~€100–500/year or Azure Trusted Signing ~$10/month).

## Debug log

Everything shown in the app console plus errors goes to
`%APPDATA%\OficinaDiag\diag.log`. If something fails, send that file — or use
the **[ SEND LOG ]** button in the app, which ships the log tail to our server
(`cloud.oficinaos.app`) for analysis. Always opt-in: nothing is sent without
the click, and the log contains only app diagnostic lines (no photos, contacts
or phone data beyond what the scan already shows).

## Privacy

The scan runs 100% locally. Nothing leaves the PC unless the user chooses
"Send to shop" or "AI" — and even then the destination is the OficinaOS
server, never opaque third parties (the AI runs with the server's key; the
data is not training data).
